# 个人修图后续计划

[English](roadmap.en.md) · [返回首页](../README.md) · [已发布的功能与限制](../CHANGELOG.md)

这份计划面向偶尔修自拍、合照、封面和生活照的人。第 41–65 项都是候选改进，具体版本和日期待定。近期优先关注四件事：升级后找回草稿（48）、看清是否保存成功（49）、拖动滑块更跟手（54）、纠正认错的人（55）。

## 导入、修图与分享

| 编号 | 计划 | 怎样算好用 |
| --- | --- | --- |
| 41 | 拖入照片或粘贴截图到图库 | 关闭来源应用后仍能重开编辑，透明截图保留透明边缘。 |
| 42 | 给常用导出规格命名 | 保存“聊天图”或“报名照”，下次直接调用，导出后可核对尺寸和体积。 |
| 43 | 缩短大 RAW 首次打开的等待 | 分别测量到首张可编辑预览的时间和内存峰值，切图时能取消上一张的解码。 |
| 44 | 改进发丝、眼镜和衣肩的抠图修边 | 换黑底或白底检查时，能补回细发丝、擦掉残边，并保留眼镜腿。 |
| 45 | 从同一原片保留多套效果 | “自然”和“暖色”可分别裁切、加蒙版、撤销和导出。 |
| 46 | 扩大手机照片和低配置 Windows 的实测 | 用逆光、夜景和小脸合照记录误认人数、纠正用时和拖动延迟。 |
| 47 | 扩充离线英文修图指令 | 同义说法和组合要求能生成可预览的提案，尊重锁定的参数和选定的人物。 |

## 图库、草稿与可靠性

| 编号 | 计划 | 怎样算好用 |
| --- | --- | --- |
| 48 | 升级时帮助找到旧图库 | 遇到空库，显示当前位置、候选旧库的照片和草稿数，让用户选择继续、恢复或新建。 |
| 49 | 说清每一步是否已保存 | 能区分预览、已存草稿和已应用编辑。写入失败时保留手头工作，重试后能接回最后一笔。 |
| 50 | 集中查看未完成的草稿 | 点一张照片就能继续相应的裁切、画笔或遮挡，完成后从草稿列表移除。 |
| 51 | 从最近使用的图库找回恢复过的库 | 重启后能分辨同名图库；外接盘离线时仍能看到上次的位置。 |
| 52 | 备份前列出需单独携带的原片 | 提前看到外接盘与离线照片的数量，换电脑时知道还需复制哪些文件。 |
| 53 | 导出或备份中断后可以重试 | 磁盘已满或外接盘断开时，可改选位置。上次成功的文件保留，半成品有明确提示。 |

## 预览、人物与局部调整

| 编号 | 计划 | 怎样算好用 |
| --- | --- | --- |
| 54 | 让曝光、蒙版等滑块更跟手 | 拖动时及时预览，松手后显示精细画面。分别测量 JPEG 和大 RAW 上的典型延迟和较慢情况。 |
| 55 | 允许纠正人物误检和漏检 | 单人封面能忽略误认的图案，合照能补选人物。应用前看清修改对象，重开后保留纠正。 |
| 56 | 支持两个蒙版取交集或相减 | 例如只提亮窗光照到的半张脸，可预览边缘、回改并撤销。 |
| 57 | 在 100% 放大时对比同一处细节 | 拖动分隔线看修前修后的眼睛、发丝或文字，画面位置和缩放保持一致。 |

## 分享与日常操作

| 编号 | 计划 | 怎样算好用 |
| --- | --- | --- |
| 58 | 一次导出多个规格 | 同一张照片一次生成头像、聊天图和高清留档，各自满足构图、尺寸和体积要求。 |
| 59 | 预览头像和封面的安全区 | 导出前可检查圆形头像会不会切到脸、横幅会不会遮住字。辅助线只在编辑时显示。 |
| 60 | 改进键盘操作和高缩放显示 | 仅用键盘就能切换人物、修蒙版、撤回笔画；在 Windows 150% 或 200% 缩放时能看清焦点。 |
| 61 | 让 AI 在多人图上先明确对象 | 输入“把她的脸提亮一点”时可点选人物，预览影响范围，确认后仅调整选中的人。 |
| 62 | 导出前集中检查分享隐私 | 一处查看遮挡、裁边和位置元数据的处理结果，检查导出文件及复制到剪贴板的成图。 |
| 63 | 固定常用工具 | 把曝光、裁切或蒙版画笔固定在显眼位置，重启和切换语言后仍可直接使用。 |
| 64 | 生成可预览的故障反馈摘要 | 用户可检查版本、图片格式和复现步骤，再决定是否分享。默认排除照片、完整路径和密钥。 |
| 65 | 按修图顺序重整并美化界面 | 围绕“导入 → 调整 → 对比 → 导出”安排主要操作。常用工具容易找到，高级选项按需展开；统一按钮名称、图标、字号、留白、对比度及选中状态。 |

**第 65 项怎样验收？** 请首次使用者独立完成三件事：导入后提亮并导出、只调整合照中的一个人、关闭后继续草稿。对照现版记录完成用时、点错或返回的次数，以及哪些步骤需要提示。中英文和 Windows 高缩放都要能辨认当前工具、选中的人物和下一步操作。
